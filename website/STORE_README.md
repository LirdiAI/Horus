# Магазин HorusClient

## Запуск
Нужен Node.js 24.x (проверен 24.21.0). В папке website выполните `npm start`, затем откройте адрес из вывода. Установка зависимостей не требуется: сервер использует стандартные модули Node.js и SQLite.

Аккаунты и заказы сохраняются в website/data/store.sqlite. Сохраняйте резервную копию всей папки data при остановленном сервере. Не публикуйте её и не загружайте в Git.

## Владелец магазина
Зарегистрируйте собственный аккаунт через сайт. В папке website выполните `npm run admin -- ВашЛогин`. Это локальная административная операция; первый зарегистрировавшийся пользователь НЕ получает права автоматически. После этого в профиле появится «Управление заказами».

Созданный заказ ждёт ручной проверки. Подтверждение в управлении заказами активирует срок либо Lifetime/Beta в базе магазина. Подтверждайте только после реальной независимой проверки оплаты. Отклонение или отмена не выдаёт доступ. Одновременно у пользователя может быть один ожидающий заказ.

## Что ещё нужно для публикации
Онлайн-оплата не подключена, деньги сайт не принимает. Нужны выбранный платёжный провайдер, реквизиты продавца, серверный обработчик подтверждённых платежей, правила продажи и возвратов. Не выдавайте доступ по одному лишь возврату браузера с оплаты.

Это отдельная защищённая база магазина. Старые Supabase-аккаунты не импортируются автоматически, старые публичные политики Supabase не изменялись. Лаунчер и Minecraft пока не подключены к этой базе. HWID не выдумывается: поле остаётся пустым и отображается «Не привязан». Для его привязки нужен отдельный аутентифицированный протокол лаунчера. Письма подтверждения и восстановление пароля не подключены.

Сервер по умолчанию слушает только 127.0.0.1 и случайный порт. Для хостинга задайте PORT, HOST, NODE_ENV=production через окружение службы; используйте HTTPS-прокси (Secure cookie включается в production), ограничение запросов на прокси, резервные копии и мониторинг. Не публикуйте старые HTML и supabase-client.js отдельным статическим сервером: новый сервер отдаёт только разрешённые страницы и ресурсы.

## Проверки
`npm test` — интеграционные проверки с временной отдельной SQLite-базой. Реальные аккаунты сайта не затрагиваются.
